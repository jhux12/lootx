# Pullz Support Overview

Pullz.gg (also branded as Pullz) is a mystery box and case-opening experience where players spend in-site coins to open cases that award items. Items you win appear in your inventory, where you can keep them, sell them back for coins, or request shipping if shipping is enabled.

Key areas visible on the site today:
- **Cases / Boxes**: Browse and open cases using coins.
- **Case Lab**: Build custom cases and publish them (see Case Lab details).
- **Case Battles**: Listed as coming soon and not yet available.
- **Bonuses / Rewards**: Bonuses exist but require account login.

If you need details that are not listed in the site UI or settings, the correct answer is **Currently not specified**.
